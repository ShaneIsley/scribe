Parallel Parsing with Rayon

Parsing JSON/CSV blobs is CPU-bound and embarrassingly parallel. par_iter() distributes work across all cores. More workers = faster total time.

Strategy 3

Hash-Based Change Detection

Two SHA-256 hashes per row: a primary key hash (stable identity, never changes) and a content hash (changes whenever any field changes). Scribe compares content hashes to decide what to write — no DB read needed.

Transactional Version History
